📡 Pocket Option — SSID (живые данные рынка)

SSID — сессионный ключ вашего аккаунта Pocket Option. По нему сайт читает реальные свечи и цены (только чтение, доступ к деньгам не даёт). Без SSID работает симуляция с пометкой.

Как получить SSID?
  1. Откройте сайт Pocket Option в браузере и войдите в свой аккаунт.
  2. Нажмите F12 — инструменты разработчика. Вкладка «Сеть» (Network) → фильтр WS.
  3. Кликните на открытое WebSocket-подключение. В «Сообщениях» найдите сообщение, начинающееся с 42["auth" (отправляется сразу после загрузки страницы).
  4. Скопируйте всё сообщение целиком (от 42 до последней }) и вставьте в поле выше.
  5. SSID живёт ограниченное время (обычно около суток). Если тест перестанет проходить — скопируйте новый.

ℹ️ О данных

Если серверу сайта Pocket Option не отвечает (например, IP хостинга заблокирован PO), сервис автоматически переключается на симулированные данные с честной пометкой на каждом сигнале. Проверить, «жив ли» ваш SSID, можно кнопкой «🧪 Тест подключения».
